# Hurdle 005: Pathlib Recursive Glob Component-Level Sorting

- **Symptom:** `test_main_dynamic_discovery_and_env` failed with `AssertionError: assert 'architecture-000' == '001-adr-000'` when asserting the first JSONL record generated by `sorted(docs_dir.rglob("*.md"))`.
- **Root Cause:** Python `Path` objects do not sort by the leaf filename (`001-adr.md` vs `architecture.md`). Instead, `PosixPath` compares path tuples component-by-component. Because `'architecture.md'` sorts alphabetically before the subdirectory name `'decisions'`, root files starting with `'a'` precede nested files inside `'decisions/'`.
- **Resolution:** Updated the unit test assertions to validate both the first record (`architecture-000` from the root directory) and the final record (`001-adr-000` from the nested `decisions/` subdirectory), confirming deterministic full-tree discovery.
