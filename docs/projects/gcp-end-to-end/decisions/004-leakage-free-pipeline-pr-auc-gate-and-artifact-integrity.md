# ADR 004: Leakage-Free Scikit-Learn Pipeline, Automated PR-AUC Gate & SHA-256 Artifact Integrity

- **Status:** Accepted
- **Date:** 2026-11-24
- **Context:** Phase 2 requires a reproducible training workflow for severely imbalanced claims triage (~2% positive base rate) that prevents preprocessing data leakage and training-serving skew, keeps model artifacts slim enough for Artifact Registry's 0.5 GB free tier, blocks underperforming models from promotion, and mitigates unsafe `pickle`/`joblib` deserialization risks before Phase 3 container serving.
- **Decision:**
  1. Bundle feature scaling (`StandardScaler`), float-cast boolean normalization (`FunctionTransformer`), and unknown-safe `OneHotEncoder(handle_unknown="ignore", sparse_output=False)` inside a single scikit-learn `Pipeline` alongside each estimator so every Stratified K-Fold split fits preprocessing strictly on training folds.
  2. Standardize on `scikit-learn`'s `LogisticRegression(class_weight="balanced")` as the linear baseline (mirroring BigQuery ML `LOGISTIC_REG`) and `HistGradientBoostingClassifier(class_weight="balanced")` as the non-linear candidate, avoiding heavier `xgboost` or `pandas` container bloat and keeping serialized `model.joblib` under 350 KiB.
  3. Enforce a strict 60/20/20 stratified train/validation/test split where 5-fold Stratified CV on train runs an automated PR-AUC promotion gate (`QualityGateError` if candidate lift fails to beat baseline), validation calibrates `TriageThresholds` (`standard_qa` and `priority_escalation`), and untouched holdout test scores final PR-AUC, ROC-AUC, recall, and precision.
  4. Record a 64-character lowercase SHA-256 hex digest of `model.joblib` inside `artifacts/metrics.json` (`ModelMetadata`, `extra="forbid"`) and enforce both path-traversal containment and constant-time `hmac.compare_digest()` hash verification inside `load_verified_artifact()` prior to calling `joblib.load()`.
- **Consequences:** Eliminates training-serving skew and silent model regressions, protects the Phase 3 inference service from tampered or escaped model artifacts, keeps container images slim, and yields grounded imbalanced performance (`+0.157` CV PR-AUC lift over baseline and `0.889` holdout ROC-AUC on 10,000 rows). Trades away GPU-accelerated gradient boosting frameworks, which are unnecessary for sub-100k tabular operations batches.
